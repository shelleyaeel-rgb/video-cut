# 烽火剪辑

个人使用的本地游戏录制与混剪工具。0.4.0 增加“三角洲录制 → 整理高光 → 音乐混剪”链路：录制时保存事件标记，停止后按标记前后截取片段，先导出完整原声集锦，再选择 BGM 与少量特效生成混剪。导入已有录像、自动扫描和手动模板继续可用。

录制链路的操作、声音范围、持久工程与恢复机制见 [录制说明](docs/RECORDING.md)。已通过真实三角洲短录像在独立窗口播放后的原生捕获、实时标记、持久工程与集锦导出闭环；这不等于实机游戏边玩边录或游戏性能验收。0.4.0 已构建并包含录制组件，具体构建与测试范围见 [验证记录](docs/VALIDATION.md)；历史 0.3.0 包保留原有导入扫描能力，不含本轮录制链路。

自动识别使用本地 RapidOCR 中文文字检测／识别模型与提示规则，并非已经训练好的三角洲专用检测模型。真实录像验证与合成流程验证分开记录，不把合成结果当作游戏准确率。实现说明见 [docs/PLAN.md](docs/PLAN.md)，实测范围和结果见 [docs/VALIDATION.md](docs/VALIDATION.md)。

## Windows 免安装版

下载或复制 `FenghuoClip-0.4.0-windows-x64.zip`，完整解压后双击 `FenghuoClip/FenghuoClip.exe`。保留旁边的 `_internal` 文件夹；Python、FFmpeg、中文 OCR、AI 人声模型与便携录制运行时随包提供，无需安装 Python 或 OBS。桌面窗口使用 Windows WebView2；若该运行时不可用，会打开系统浏览器继续使用。退出时展开“工具与应用信息”，点击“退出应用”；先结束录制并等待“已保存”，导出任务则等待或取消。

“工具与应用信息”中的“版本与更新”提供检查、下载和重启安装。应用版本更新在主动点击时检查，剪辑与 AI 推理在本机处理。尚未发布正式版本、仓库不可访问或断网时会显示原因，现有版本继续可用。私有仓库认证、构建发布和数据目录详见 [桌面版说明](docs/DESKTOP.md)。

免安装版的模板、偏好设置、日志、缓存及输出保存在 `%LOCALAPPDATA%\FenghuoClip`，与程序目录分开。常用时长、音量、特效、阈值和编码选项会保存；导入模式的素材路径、扫描结果和排除记录不跨会话恢复。新增录制工程另外持久保存原片路径、标记、选择和片段范围。

## 从源码在这台电脑上启动

双击项目根目录的 `start.cmd`，浏览器会打开本机工作台。保持启动窗口运行；关闭工具时可在窗口按 Ctrl+C。

或运行：

```powershell
.\.venv\Scripts\python.exe -m videocut.launcher --open
```

默认地址 `http://127.0.0.1:8765`。端口被占用时可指定 `--port 8766`。只监听本机地址，媒体在本机处理，不上传录像或音频。

源码录制功能还需要便携录制组件，在项目根目录运行一次：

```powershell
.\.venv\Scripts\python.exe scripts\download_capture.py
```

脚本下载并校验固定版本的 OBS/libobs 与独立 Python 运行时，保存在项目 `.tools/obs`，不安装系统 OBS，也不要求用户打开 OBS。组件下载需要网络，录制由本机运行时处理。组件未就绪时页面会显示原因，导入剪辑仍可使用。

## 使用流程

### 录制与高光

1. **开始录制**：点击窗口列表旁的“刷新”，选择三角洲窗口或显示器，选择系统声音或静音，再开始录制。支持 1080p、30/60 帧；系统声音包含当前播放设备上的其他应用声音。
2. **整理高光**：自动识别目前面向中文、16:9、默认 HUD 的已观察提示布局；录制中也可按 `Ctrl+Alt+F8` 或点击“添加标记”。结束后等待“已保存”，从录制记录打开工程，预览、排除或手动补充事件。默认保留事件前 5 秒、提示结束后 2 秒。
3. **导出与混剪**：“导出原声集锦”保留全部勾选事件、合并重叠片段，不受 90 秒预算或 10 秒单镜头限制。“选择音乐与特效”进入混剪，按目标时长精选并使用干净剪辑、轻量卡点或击杀冲击预设。两种导出都直接读取原片，不把已压缩的集锦再作为混剪输入。

自动识别出现积压或故障时，录像可继续并记录识别缺口；停止后可“补查整段提示区”。补查保留手动标记，已有人工选择尽量按事件类型与时间对应；新发现或身份不明确的自动事件需要重新勾选。异常中断的录像可尝试恢复，原始残留文件始终保留。

### 导入已有录像

1. **选择素材**：选择或粘贴录像路径，背景音乐可选。音乐留空时保留所选原声和已开启的效果音。
2. **扫描并预览事件**：默认“三角洲 · 自动识别”和“整段录像”。也可切换“指定片段”，输入起点及 5–60 秒时长，先验证已知有提示的一段。扫描可取消，不依赖音乐或 AI 人声组件。
3. **核对候选**：点击事件查看原片画面，可前后移动 0.5 秒；不需要的事件勾选排除。自动模式暂不区分玩家／小兵，默认保留为待确认。识别分数是文字与提示规则的依据，不是准确率。
4. **生成混剪**：设置目标时长和特效后生成，完成后预览、保存或打开输出文件夹。也可直接生成，由程序扫描全片。页面分别显示候选数、过滤数、实际入选事件数和镜头数。

完整扫描在当前服务会话中缓存时间清单，生成时核对源文件、配置和签名后复用；局部扫描不会替代全片扫描。整段扫描的排除按事件 ID 精确应用，避免把同一时段的其他事件一起删除；局部排除只匹配单个候选，存在歧义时要求重新扫描。修改录像或识别设置后，页面清空旧结果及排除记录。

默认保留事件前 5 秒、提示结束后 2 秒，单次持续提示最多增加 3 秒尾部。相邻事件合并为交战镜头，单镜头上限 10 秒，较长交战在事件边界拆分，再按目标时长精选。素材不足时生成更短的集锦；没有候选时明确提示。

### 收起的高级功能

- **声音与导出设置**：音乐起点与音量、原声音量、OBS 独立游戏音轨、CPU／NVIDIA 编码。录像人声和 BGM 默认保留，也可分别启用 AI 减弱人声／提取伴奏，使用说明见 [docs/AUDIO.md](docs/AUDIO.md)。
- **识别设置与手动模板**：可切换已有配置或新建手动模板；模板模式继续支持击倒、击杀、爆头、背景蒙版、擦除背景、独立阈值和玩家／小兵辅助标记。选择原片时间、读取画面、框选稳定图标或固定文字，预览后保存，再用指定片段验证。自动模式不使用模板阈值。
- **工具与应用信息**：合成演示、日志、版本更新和退出应用。演示生成四个已知事件与节拍音乐，加载后点击“生成混剪”即可验证流程；演示采用独立模板，不代表自动 OCR 的真实游戏效果。

模板辅助标记只接受与本人事件同时出现的专属依据，不应选队友播报或常驻 HUD。依据冲突或缺失时保留待确认；有可靠小兵依据时自动过滤。过滤仅取消该事件的选片触发，它仍可能出现在另一事件的前后片段中。旧单模板和多模板配置继续可用。

## 在另一台 Windows 电脑上运行源码

准备 **Python 3.12 x64** 和网络，复制源码（无需复制 `.venv`、`work`、`outputs`），然后：

```powershell
# 若使用本机已安装的 Python，请显式传入路径。
.\scripts\setup.ps1 -Python 'C:\完整路径\python.exe'
```

在当前 Codex 环境中，脚本也能定位已提供的 Python。安装会创建项目内 `.venv` 和 `.tools`，不更改系统 PATH。依赖版本固定；下载按 PyPI 的 SHA-256 校验。RapidOCR 随包提供中文 ONNX 模型，扫描时不再下载；ONNX Runtime 固定为 1.20.1（本机 1.22.1 曾发生 DLL 加载失败）。OpenCV 使用 `opencv-python`，不与 `opencv-python-headless` 并装；在线安装脚本会迁移旧依赖。FFmpeg 从 Gyan 官方构建站下载，校验发布者提供的 SHA-256，实际下载信息在 `.tools/ffmpeg-download.json`。若 PyPI 文件下载慢，可加 `-PackageMirror 'https://mirrors.aliyun.com/pypi'`，仍使用 PyPI 官方哈希核验。

此处虚拟环境依赖安装时的 Python，不可直接搬走；另一台电脑日常使用建议选择上面的免安装版。CPU 模式默认可用；NVIDIA 模式需要合适驱动和硬件，失败会提示并回退 CPU。

需要 AI 人声处理时，额外运行 `.\.venv\Scripts\python.exe scripts\setup_audio.py` 下载约 64 MiB 的模型。本次电脑已完成安装；AI 音频使用 CPU，NVIDIA 选项只用于视频编码。

## 文件和空间

以下为数据根目录内的相对路径：源码版默认项目目录，免安装版默认 `%LOCALAPPDATA%\FenghuoClip`。

- `outputs/<任务ID>/montage.mp4`：成片。
- `outputs/<任务ID>/events.json`：全部候选的事件 ID、时间、识别分数、文字或模板依据、分类，以及是否保留和过滤原因。
- `outputs/<任务ID>/manifest.json`：选片时间线、参数、候选／过滤／入选统计与实测用时。
- `recordings/<录制ID>/source.mkv`：原始录制；同目录 `previews/` 存按需生成的短片预览，恢复结果另存为 `recovered-*.mkv`。
- `data/projects.sqlite`：录制工程、封存资产、稳定事件 ID、微秒时间戳、识别缺口、选择与剪辑设置；运行时可能有 SQLite 的 `-wal`、`-shm` 文件。
- `data/profiles/`：用户标定的检测模板。
- `data/preferences.json`：常用剪辑参数。
- `work/jobs/`：候选片段和效果音缓存；只存选中的片段，不保存全片逐帧图片。
- `work/demo/`：合成演示素材。
- `work/audio-cache/`：成功的人声分离结果，可跨任务复用；不自动清理。
- `work/logs/`：当前启动、运行、任务、FFmpeg 和页面日志。
- `work/errors/`：旧版留下的错误日志，保留但不再写入。
- `work/downloads/`：下载缓存，可在确认安装成功且无需离线安装后自行清理。

任务缓存便于排查，当前不会自动删除。录制停止并封存后，剪辑只读原片；恢复另存新文件。上述媒体、缓存、依赖和本地配置不应提交源码，上传前仍应检查提交内容。备份录制工程时先退出应用，再一起备份 `recordings` 和 `data/projects.sqlite`。

## 出错时查看日志

展开页面底部“工具与应用信息”，点击 **“打开日志文件夹”**，或直接进入项目下的 `work\logs`。也可以点击 **“下载日志”** 保存 ZIP，包含当前日志和轮转备份，不含录像。受限环境无法打开资源管理器时，页面会显示可手动复制的完整路径。页面报错会显示错误编号；已启动的剪辑任务另有任务编号。把编号、发生时间和当时的操作一起提供，就能定位对应记录。启动失败时也可直接打开这个目录，无需网页正常运行。

| 文件 | 记录内容 | 单文件大小 / 备份数 |
| --- | --- | --- |
| `startup.log` | 启动环境、依赖和工具版本、端口占用、依赖缺失、启动异常堆栈 | 2 MiB / 2 |
| `runtime.log` | 无效路径、参数校验、标定和接口异常，带请求编号 | 5 MiB / 3 |
| `tasks.log` | 任务开始、进度、素材参数、候选与镜头数量、完成、取消、失败堆栈及耗时 | 5 MiB / 3 |
| `ffmpeg.log` | FFmpeg/ffprobe 命令参数、逐行诊断输出、退出码、超时、取消及耗时 | 10 MiB / 4 |
| `frontend.log` | 页面捕获的运行错误、未处理异常和 Promise 拒绝，带页面错误编号 | 2 MiB / 2 |
| `bootstrap.log` | 用 `start.cmd` 启动时 Python 缺失或无法启动的简短记录 | 约 64 KiB / 1 |

文件按需创建，以 UTF-8 JSON Lines 保存（每行一条记录）。超过大小后自动轮转为 `.log.1`、`.log.2` 等，最旧备份自动淘汰；总占用约 **102 MiB**，不含历史 `work/errors` 和媒体缓存。FFmpeg 在轮转保留期内保存全部 stderr 诊断文本；页面只显示末尾摘要，不记录视频帧或音频二进制内容。硬件编码回退 CPU 时保留原始失败原因。

日志包含本地素材路径、参数和系统版本，保存在本机，不自动上传；会话令牌及常见凭据字段会脱敏。可以用记事本打开日志并搜索编号。

服务断连时，当前页面最多暂存最近 20 条错误；连接恢复后自动补交。服务重启后如提示会话失效，刷新同一个标签页即可补交。关闭标签页会丢失尚未补交的记录；如果浏览器禁止暂存，页面会提示刷新也会丢失记录。脚本尚未加载、浏览器崩溃、断电或进程被强制结束时，无法保证有最后一条错误记录。日志无法写入时，页面会提示检查空间和权限。

`python -m videocut.server` 旧启动方式仍可用，也会经过同一个启动日志入口。

## 当前限制

- 内置录制仅面向 Windows；首版采用系统输出声音，没有麦克风和按应用独立分轨，也没有暂停、回放缓存或自动启动游戏。游戏内帧率影响、长录制漂移、设备热切换与跨机兼容性仍需专项验收。
- 实时识别使用固定的三角洲中文 16:9 默认 HUD 提示区域，要求至少 720p 源画面；其他语言、超宽屏、HUD 缩放、不同模式及短暂提示可能漏检。识别缺口表示没有完成处理，“没有缺口”不代表没有漏检。录后补查仍使用同一提示区域与规则。
- 支持单视频和可选的单 BGM；输出 SDR、最高 1080p、30 fps、H.264/AAC。HDR 素材明确拒绝，不做未经验证的色彩转换。
- 自动识别依据提示文字、邻近白色图标和跨帧变化；小字、动画、背景、遮挡及相似提示仍会造成误检或漏检，玩家／小兵分类暂待人工确认。不是视觉大模型，也不判断“一打三”“灭队”或精彩程度。
- 击倒与补杀尚未可靠关联到同一目标；不同事件提示刷新时会尝试分开记录，同一持续提示去重。手动模板可作为补充，仍需核对样本与阈值。
- 音乐分析检测能量突变点，靠近切点时尝试对齐；不保证理解强拍、乐句、高潮或自动选副歌。
- 特效为固定模板；没有字幕、复杂转场、抠像或人工编辑时间线。
- 人声分离使用现成音乐模型，属于试验功能；不能保证干净去除玩家、队友语音或完整保留枪声，真实游戏处理效果仍需试听。
- 没有高光时会失败提示；高光少时输出短片。添加 BGM 后，音乐剩余时长不足时缩短上限，不自动循环歌曲；无 BGM 时按目标时长选片。
- 验证使用 CPU 路径和已取得的真实短样本；RTX 5080、小时级吞吐和跨场景准确率以单独实测为准，不由短片结果推定。
- 服务重启后导出任务面板不恢复历史，但已完成的视频和清单保留在 `outputs`；录制工程通过 SQLite 恢复，未完成录制进入待恢复状态。
